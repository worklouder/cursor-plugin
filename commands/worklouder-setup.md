---
name: worklouder-setup
description: Open Work Louder pairing, layer setup and preferences
---
Open the local Work Louder setup page using the included worklouder MCP server's worklouder_setup tool. The user chooses pairing and any layer installation in that page. Report whether the page opened. If the server is disabled, ask the user to enable the plugin's worklouder MCP server in Cursor settings and retry. Do not change device settings or send chat messages on the user's behalf.
