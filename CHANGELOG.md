# Changelog

## 1.0.0

First public release on the Cursor Marketplace.

- Six Agent Keys that open your chats in the Agents Window and show their status with lighting.
- Dial navigation between chats, plus New Chat, Model Picker, Approve, Decline, Send and hold-to-talk controls.
- A guided setup page for pairing with Input and adding the bundled Cursor layer.
- Settings for brightness, dimming, the off timer and how chats are arranged on the keys.
- Support for macOS and Windows using the runtime that ships with Cursor.
